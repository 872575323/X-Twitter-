# X/Twitter 浏览增强器

一个 Tampermonkey 用户脚本，让 X（Twitter）网页版更适合宽屏阅读：双列信息流、可折叠左侧菜单、隐藏右侧栏和推广推文。

## 功能

| 功能 | 默认 | 说明 |
|---|---|---|
| 双列布局 | 开 | 信息流按瀑布流排成两列，支持无限滚动；窗口可用宽度不足 700px 时自动回退单列 |
| 隐藏右侧边栏 | 开 | 隐藏趋势、推荐关注等右侧栏，主内容区占满剩余宽度 |
| 隐藏推广推文 | 开 | 隐藏带 "Ad / Promoted / 推广 / 广告" 标签且没有时间戳的推文 |
| 隐藏 Grok | 开 | 隐藏左侧 Grok 入口、Grok 抽屉和推文上的 Grok 按钮 |
| 折叠左侧菜单 | 关 | 左侧导航只保留图标，宽度收窄到 88px |
| 紧凑模式 | 关 | 减小推文间距和头像尺寸 |
| 隐藏浮动发帖按钮 | 关 | 隐藏左侧 "发帖" 按钮 |

设置面板会跟随 X 的主题（默认、暗蓝、纯黑）切换配色。所有开关状态会保存，刷新后保留。

## 安装

1. 安装浏览器扩展 [Tampermonkey](https://www.tampermonkey.net/)。
2. 打开 [x-enhancer.user.js 原始文件](https://raw.githubusercontent.com/872575323/X-Twitter-/main/x-enhancer.user.js)，Tampermonkey 会弹出安装页，点 "安装"。
3. 打开或刷新 [x.com](https://x.com)。

脚本带有 `@updateURL`，Tampermonkey 会按自身的检查周期从本仓库自动更新。

## 使用

- 右下角齿轮按钮：打开设置面板。
- 屏幕左边缘中部的小箭头：折叠 / 展开左侧菜单。

快捷键（光标在输入框里时不生效）：

| 快捷键 | 作用 |
|---|---|
| `Alt` + `S` | 折叠 / 展开左侧菜单 |
| `Alt` + `R` | 显示 / 隐藏右侧边栏 |
| `Alt` + `D` | 开 / 关双列布局 |
| `Alt` + `X` | 打开 / 关闭设置面板 |

快捷键按物理键位识别，Mac 上用 `Option` 代替 `Alt`。

## 双列布局的实现方式

X 的时间线是虚拟列表：每条推文是一个绝对定位的 `cellInnerDiv`，X 测量每个 cell 的高度后用 `translateY` 排列，并只渲染视口附近的 cell。纯 CSS 的 flex / grid 无法改变这种排列。

脚本把每条推文 cell 的高度设为（实际高度 + 间距）/ 2，这样 X 自己计算出的坐标和两列瀑布流的平均高度基本一致，X 渲染的范围始终覆盖视口，滚动不会出现空白，无限加载也照常触发。在此基础上，脚本再把推文分配到左右两列，已排过的推文固定在原列，滚动时不会左右跳动。非推文内容（如 "推荐关注"）按通栏显示。

脚本只用一个 `MutationObserver`（监听时间线增删和 X 改写 transform）和一个 `ResizeObserver`（监听推文高度变化，例如图片加载完成），在下一帧统一重排。

## 已知限制

- 快速滚动时，图片尚未加载完的推文高度会变化，可能出现一两帧重叠，停下后会自动修正。
- 推广推文按页面上的标签文字识别。X 改版或使用其他界面语言时可能漏判，欢迎提 Issue 并附上推文的 DOM 结构。
- 脚本依赖 X 页面上的 `data-testid` 和部分 DOM 结构，X 改版后部分功能可能失效。

## 兼容性

在 Chrome + Tampermonkey、X 网页版（2026 年 11 月版本）上测试。需要浏览器支持 CSS `:has()` 和 `ResizeObserver`（Chrome 105+、Edge 105+、Firefox 121+、Safari 15.4+）。
